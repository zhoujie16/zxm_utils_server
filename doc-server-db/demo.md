## 表概览

- **表名**：`demo`
- **中文名称**：示例表
- **主要用途**：用于演示与测试 CRUD 接口的示例业务表，不参与核心业务逻辑，便于开发阶段验证接口、前端联调等。

## 字段说明

| 字段名       | 类型          | 约束           | 允许为空 | 默认值 | 说明 |
| ------------ | ------------- | -------------- | -------- | ------ | ---- |
| `id`         | INTEGER       | 主键，自增     | 否       | —      | Demo 记录主键 ID。 |
| `name`       | VARCHAR(100)  | —              | 否       | —      | 名称，示例实体的名称字段。 |
| `description`| TEXT          | —              | 是       | `NULL` | 描述，可选字段，用于补充说明。 |
| `createdAt`  | DATETIME      | —              | 否       | 当前时间 | 记录创建时间，由 ORM 自动维护。 |
| `updatedAt`  | DATETIME      | —              | 否       | 当前时间 | 记录最近更新时间，由 ORM 自动维护。 |

## 约束与索引

- **主键约束**
  - `PRIMARY KEY (id)`

- **索引**
  - 当前表仅有主键索引，未定义额外业务索引。

## 典型使用说明

- **写入来源**
  - 由 Demo 模块的接口进行增删改操作，通常用于开发阶段的示例或调试：
    - 创建：`POST /demo`。
    - 更新：`PATCH /demo/:id`。
    - 删除：`DELETE /demo/:id`。
- **读取场景**
  - 获取列表：`GET /demo`。
  - 获取单条详情：`GET /demo/:id`。
  - 该表不承载核心业务，仅作为示例数据结构，用于验证：
    - 后端 CRUD 流程；
    - 前端表单与列表展示；
    - 通用错误处理与权限控制流程。
