## 表概览

- **表名**：`vehicle_track`
- **中文名称**：车辆轨迹表
- **主要用途**：存储从途强平台同步的车辆行驶轨迹点数据，用于轨迹回放、地图展示、按时间范围查询、缺失坐标补全等功能。

## 字段说明

| 字段名       | 类型          | 约束                                   | 允许为空 | 默认值                 | 说明 |
| ------------ | ------------- | -------------------------------------- | -------- | ---------------------- | ---- |
| `id`         | INTEGER       | 主键，自增                             | 否       | —                      | 轨迹记录主键 ID。 |
| `imei`       | VARCHAR(50)   | 索引 `idx_imei`                        | 否       | `'868120325700570'`    | 设备 IMEI，用于标识车辆设备，目前系统中固定为单一设备。 |
| `direction`  | INTEGER       | —                                      | 否       | `0`                    | 行驶方向，单位为度。 |
| `gateTime`   | BIGINT        | 索引 `idx_gateTime`                    | 否       | —                      | 门时间戳，13 位毫秒时间戳，来自外部数据的门事件时间。 |
| `gpsMode`    | INTEGER       | —                                      | 否       | `0`                    | GPS 模式，表示定位模式或信号状态。 |
| `gpsSpeed`   | REAL          | —                                      | 否       | `0`                    | GPS 速度，单位 km/h。 |
| `gpsTime`    | BIGINT        | 索引 `idx_gpsTime`，唯一索引见下方说明 | 否       | —                      | GPS 时间戳，13 位毫秒时间戳，是轨迹主时间字段。 |
| `lat`        | REAL          | —                                      | 否       | —                      | BD-09 坐标系纬度（百度地图原始坐标）。 |
| `lng`        | REAL          | —                                      | 否       | —                      | BD-09 坐标系经度（百度地图原始坐标）。 |
| `lat_gcj02`  | REAL          | —                                      | 是       | `NULL`                 | GCJ-02 坐标系纬度（高德/国测局坐标），由批量转换任务填充。 |
| `lng_gcj02`  | REAL          | —                                      | 是       | `NULL`                 | GCJ-02 坐标系经度（高德/国测局坐标），由批量转换任务填充。 |
| `posMethod`  | INTEGER       | —                                      | 否       | `0`                    | 定位方法，表示定位方式（如 GPS、基站等）编码。 |
| `posMulFlag` | INTEGER       | —                                      | 否       | `0`                    | 定位多重标志，用于标记多种定位信息的组合情况。 |
| `posType`    | INTEGER       | —                                      | 否       | `1`                    | 定位类型，区分不同业务含义的定位点类型。 |
| `precision`  | INTEGER       | —                                      | 否       | `0`                    | 精度指标，数值越大通常表示定位精度越高。 |
| `createdAt`  | DATETIME      | —                                      | 否       | 当前时间（插入时自动） | 记录创建时间，由 ORM 自动维护。 |
| `updatedAt`  | DATETIME      | —                                      | 否       | 当前时间（更新时自动） | 记录最近更新时间，由 ORM 自动维护。 |

## 约束与索引

- **主键约束**
  - `PRIMARY KEY (id)`

- **唯一约束**
  - `UNIQUE (imei, gpsTime)`  
    同一设备在同一 GPS 时间戳只允许存在一条轨迹，避免重复同步。

- **索引**
  - `INDEX idx_imei (imei)`：按设备查询轨迹时加速检索。
  - `INDEX idx_gateTime (gateTime)`：按门时间范围查询时使用。
  - `INDEX idx_gpsTime (gpsTime)`：按 GPS 时间范围查询、排序时使用，是列表查询的主要排序字段。

## 典型使用说明

- **写入来源**
  - 由车辆轨迹模块的同步任务从途强 API 拉取数据，并写入本表（只插入新数据，不更新已有记录）。
  - 去重逻辑基于 `(imei, gpsTime)` 组合键。
- **读取场景**
  - 车辆轨迹列表查询：按时间范围分页查询，并可筛选缺少 GCJ-02 坐标的记录。
  - 批量坐标转换任务：扫描 `lat_gcj02` 或 `lng_gcj02` 为空且 `lat/lng` 非空的记录，对接百度坐标转换 API，将结果写回。
